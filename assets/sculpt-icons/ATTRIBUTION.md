# Blender sculpt brush icons

Toolbar PNGs are Blender’s classic sculpt brushicons
(`release/datafiles/brushicons/`), sourced from the
[blender/blender](https://github.com/blender/blender) tree at tag `v4.0.0`.

They are the sphere-style brush previews used in Blender’s sculpt UI
(Draw, Clay, Inflate, Smooth, Flatten, Pinch, Crease, Grab, Snake Hook, …).

Blender later moved brush assets into the Essentials library
([blender-assets](https://projects.blender.org/blender/blender-assets)),
which is explicitly **CC0**. These PNGs are the same visual family;
use with attribution to the Blender Foundation when redistributing.

Mapping used by MUSGO:

| MUSGO tool | Blender brushicon |
|---|---|
| brush | draw |
| clay | clay |
| inflate | inflate |
| smooth | smooth |
| flatten | flatten |
| pinch | pinch |
| crease | crease |
| drag | grab |
| scale | snake_hook |
